# QATechAssessment

# About :
This Solution is designed for both UI & API based automation Framework using Selenium Webdriver using C# for Web UI Based Automation and RestSharp HttpRestClient for API based Automation.

# Tools Required to Execute :
1. Visual Studio 2015 +
2. Visual Studio Extensions (NUnit 3 VS Adapter)
All the other references and Nuget Packages are auto installed during the build process.
